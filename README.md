# Financial Performance & Risk Analysis of Major Technology Companies

## Project Overview

This project analyzes the stock market performance of major technology companies using Python and Tableau. The analysis focuses on stock price trends, total returns, volatility, moving averages, daily return fluctuations, and risk-return positioning.

The project was built to demonstrate practical financial analysis, data visualization, and analytical dashboard development skills.

---

## Companies Analyzed

- Apple (AAPL)
- Microsoft (MSFT)
- NVIDIA (NVDA)
- Tesla (TSLA)

---

## Tools & Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- yFinance
- Tableau
- Microsoft Excel

---

## Project Objectives

- Analyze long-term stock performance
- Compare total returns across companies
- Measure annualized volatility
- Study daily stock return fluctuations
- Visualize moving average trends
- Evaluate risk-return relationships

---

## Methodology

### 1. Data Collection
Historical stock market data was collected using the `yfinance` Python library.

### 2. Data Processing
Python was used to:
- clean and organize stock price data,
- calculate daily returns,
- compute annualized volatility,
- generate moving averages,
- prepare datasets for Tableau visualization.

### 3. Dashboard Development
Interactive dashboards and visualizations were created using Tableau.

---

## Key Metrics Used

### Daily Returns
Measures day-to-day percentage change in stock prices.

### Annualized Volatility
Used to estimate the risk level of each stock.

### Total Return
Measures overall stock growth during the selected period.

### 50-Day Moving Average
Used to smooth price fluctuations and identify long-term trends.

### Risk vs Return Analysis
Compares stock performance relative to volatility.

---

## Dashboard Components

### 1. Stock Price Trends
Visual comparison of stock price movements from 2020–2025.

### 2. Total Return Comparison
Comparison of overall percentage returns across companies.

### 3. Volatility Comparison
Analysis of annualized stock volatility.

### 4. Daily Returns Trend
Visualization of short-term stock return fluctuations.

### 5. 50-Day Moving Average Trends
Smoothed trend analysis using moving averages.

### 6. Risk vs Return Analysis
Scatter plot comparing volatility and total returns.

---

## Key Insights

- NVIDIA delivered the highest total return among selected companies.
- Tesla exhibited the highest volatility, indicating greater market risk.
- Microsoft demonstrated comparatively stable and consistent long-term growth.
- Apple maintained a balanced risk-return profile.
- NVIDIA and Tesla showed stronger growth momentum but with elevated volatility.
